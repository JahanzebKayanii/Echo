## Features

- **Audio Transcription** — Upload any meeting recording and get a word-accurate transcript powered by Deepgram nova-2
- **Live Recording** — Record meetings directly in the browser; a Chrome extension lets you capture any tab or screen and send it straight to Echo
- **Speaker Diarization** — Automatically separates speakers and lets you rename them manually
- **AI Speaker Identification** — Claude scans the transcript for name mentions and auto-labels speakers
- **AI Summaries** — One-click meeting summaries generated by Claude
- **Action Item Extraction** — Automatically pulls out tasks, owners, and deadlines
- **AI Chat** — Ask questions about any meeting and get answers grounded in the transcript
- **Notes** — Add free-form notes to any meeting
- **Tags** — Tag meetings for organisation
- **Multilingual** — Choose a transcription language per upload
- **Export** — Download transcripts and summaries as PDF or Excel
- **Search** — Search across meeting titles, descriptions, and transcripts
- **Authentication** — Email/password or OAuth via Google, GitHub, or Microsoft
- **Account Management** — Update profile, view stats, and delete account from the settings page

## Running Locally

### Prerequisites
- Python 3.10+
- Node.js 18+
- PostgreSQL database

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate       # Windows
pip install -r requirements.txt
```

Create a `backend/.env` file:

```
DATABASE_URL=postgresql://user:password@localhost:5432/echo_db
DEEPGRAM_API_KEY=your_deepgram_key
CLAUDE_API_KEY=your_claude_key
SECRET_KEY=your_secret_key
ALLOWED_ORIGINS=http://localhost:5173

# OAuth (optional)
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
MICROSOFT_CLIENT_ID=your_microsoft_client_id
MICROSOFT_CLIENT_SECRET=your_microsoft_client_secret
```

```bash
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
```

Create a `frontend/.env` file:

```
VITE_API_URL=http://127.0.0.1:8000
```

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Chrome Extension

The extension records meetings from any browser tab and sends them directly to Echo for transcription.

To load it locally:
1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select the `extension/` folder
